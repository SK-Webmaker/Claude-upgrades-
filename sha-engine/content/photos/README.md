# Sha's own client photography

Real work, shot in the salon, sourced from her website repo
(`SK-Webmaker/HairbySha`, `public/images/`). Every one is a genuine client
result — no stock, no AI. See CLAUDE.md invariant 2.

All three are back-of-head with no face in frame, and all three are already
published on her own public website, so there is no consent question in reusing
them for her own advertising. If a photo with a recognisable face is ever added
here, check `brand.json` → `consent` first: the policy is `blanket_at_booking`
with `requireFaceBlurWithoutConsent: true`.
