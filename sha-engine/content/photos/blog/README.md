## One deliberately not kept

`IMG_0457.jpg` from the same set shows **a client's face clearly and in focus**.
`brand.json` sets `consent.requireFaceBlurWithoutConsent: true` and there is no
way to confirm from here whether that client agreed to appear in marketing, so it
was downloaded, reviewed, and deleted rather than left in the repo. Her own site
publishing it is not the same as consent to reuse it in an ad.

`blog-05` shows Sha herself, which is fine — `voice.onCamera` is `face_and_voice`
and it is her business.
